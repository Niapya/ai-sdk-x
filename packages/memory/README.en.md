# @ai-sdk-x/memory

Memory is a tool for adding memory to an Agent.

This package provides primitives for storing and retrieving context information that can be used by agents during interactions.

## Examples

For the MySQL variant, see [MySQL Memory](./src/examples/mysql.ts) example.
For the SQLite variant, see [SQLite Memory](./src/examples/sqlite.ts) example.
For the PostgreSQL variant, see [PostgreSQL Memory](./src/examples/postgresql.ts) example.
