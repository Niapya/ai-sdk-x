# @ai-sdk-x/memory

[English](./README.en.md) | 简体中文

Memory 是一个为 Agent 添加记忆的工具。

这个包提供了存储和检索上下文信息的原语，Agent 可以在交互过程中使用这些信息。

## 例子

关于 MySQL 的变体，请看 [MySQL 记忆](./src/examples/mysql.ts)的例子。
关于 SQLite 的变体，请看 [SQLite 记忆](./src/examples/sqlite.ts)的例子。
关于 PostgreSQL 的变体，请看 [PostgreSQL 记忆](./src/examples/postgresql.ts)的例子。
