# AI SDK X

Your AI SDK may only need this one tool.

> AI SDK X v0 keeps the full package set for execute, memo, memory, and skill. If you're starting fresh, switch to V1 for the latest guide-first experience.
>
> Use the article list below to navigate the full V0 documentation.

## Installation

Install all packages at once via the umbrella package:

```bash
# npm
npm install ai-sdk-x

# bun
bun add ai-sdk-x

# pnpm
pnpm add ai-sdk-x

# yarn
yarn add ai-sdk-x

# Deno
deno add npm:ai-sdk-x
```

Or install individual packages:

```bash
npm add @ai-sdk-x/execute @ai-sdk-x/memo @ai-sdk-x/memory @ai-sdk-x/skill
```

## Peer Dependencies

```bash
npm add ai zod
```
