# ai-sdk-x

AI-SDK-X 是构建一系列环境无关的代理工具包，旨在 AISDK 上打造一个更轻松地打造一个 Agent。

使用 AIS-DK-X 使得您无论在本机上，服务器上，还是使用外部服务，还是 Serveless 环境，都可以轻松地构建和部署智能代理。

这个项目是一个单体仓库，包含多个包，你可以进入每个包的目录查看 README 来了解更多细节。

```bash
# 安装所有 ai-sdk-x 包
bun add ai-sdk-x
npm install ai-sdk-x
yarn add ai-sdk-x
pnpm install ai-sdk-x
deno add npm:ai-sdk-x

# 或者安装特定的包
npm add @ai-sdk-x/memo @ai-sdk-x/execute @ai-sdk-x/skill @ai-sdk-x/memory
```
